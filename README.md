# 교양 앱

10분이면 한 장씩 읽는 교양 앱 세 개예요. 앱마다 HTML 파일 하나에 디자인·기능·내용이 모두 들어 있어요.

- [10분 상식](https://ssiissx.github.io/culture-apps/sangsik.html) — 역사·미술·철학심리·과학·음악
- [알고 가면 보이는 일본](https://ssiissx.github.io/culture-apps/japan.html) — 역사와 사건, IP, 요즘 문화, 그늘
- [알고 보면 새로운 한국](https://ssiissx.github.io/culture-apps/korea.html) — 역사와 사건, K-콘텐츠, 요즘 문화, 그늘

## 아이폰 홈 화면에 추가하기

사파리로 위 주소를 열고 공유 버튼 → '홈 화면에 추가'. 첫 화면을 추가하면 아이콘 하나로 세 앱을 오가고, 앱마다 따로 추가해도 돼요.
한 번 연 뒤에는 인터넷 없이도 열려요(서비스 워커가 세 앱을 모두 폰에 저장). 새 버전을 올리면 다음번에 열 때 바뀌어요.
읽음 표시·즐겨찾기·글자 크기·밝게/어둡게 설정은 기기에 저장되고, 사파리와 홈 화면 앱의 기록은 서로 따로예요.

## 내용 고치는 법

1. 앱 파일(`sangsik.html` 등)을 열고 `카드 데이터 시작`을 찾으세요.
2. 카드 하나가 `<article> … </article>` 한 덩어리예요. 제목은 `<h2>`, 묶음·주제·아이콘은 `data-group`·`data-topic`·`data-emoji` 값이에요.
3. 새 카드는 비슷한 카드를 통째로 복사해 붙이고 `id`만 새 이름(예: `n4`)으로 바꾸세요. 이미 있는 `id`는 읽음 기록과 연결돼 있으니 바꾸지 마세요.
4. 목록, 장 수, 이전·다음 버튼은 열 때 자동으로 맞춰져요.
5. 고친 뒤에는 `sw.js`의 `VERSION` 값을 아무 글자로나 바꿔야 홈 화면 앱이 새 내용을 받아요. (작업 파일의 `site.py`로 다시 만들면 자동으로 바뀌어요.)
6. 제목에 처음 쓰는 글자가 들어갔다면 `python tools/fetch_fonts.py`를 한 번 실행하세요. 제목 글꼴(함렛)을 그 글자까지 다시 받고 `sw.js`의 저장 목록도 맞춰 줘요. 그다음 5번처럼 `VERSION`을 바꾸면 돼요. (`site.py`로 `sw.js`를 다시 만들 때는 `fonts/` 폴더 파일도 저장 목록에 들어가야 해요.)

자세한 안내는 각 파일 맨 위 주석에 있어요.
